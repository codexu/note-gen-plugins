# 插件能力实验室

Plugin Playground 是用于手动测试和学习 NoteGen 插件开发的官方示例。插件 ID 为 `top.notegen.plugin-playground`。它提供 32 项可运行操作，以及视图、表单、弹窗、菜单和事件示例。

## 开始使用

1. 安装插件后，通过命令面板的“打开插件能力实验室”、状态栏 Lab、编辑器斜杠菜单／右键菜单、文件右键菜单或移动端写作菜单进入。
2. 在插件设置中选择测试目录，默认 `PluginPlayground`。在插件权限页将所需笔记与附件权限授权到该目录；编辑器权限授权到活动编辑器，网络权限只需 `https://notegen.top`。设置目录不会自动授予权限。
3. 点击“一键演示全部能力”，自动准备测试笔记和附件、依次执行全部 32 项操作，并打开左右侧栏、标签页和弹窗。无需逐项选择或重复确认。也可以直接从命令面板运行“一键演示全部插件能力”。
4. 结果区显示返回值或宿主错误码。覆盖表记录本次成功／失败的操作；事件表通过“刷新结果与事件”更新。

全部权限都是可选的。没有授权时仍可体验界面、日历、存储和设置；需要权限的调用会显示 `PermissionDenied`。授权或撤销权限可能由宿主重启插件，此时需要重新创建测试文件。

一键演示会读写插件示例存储、访问 `https://notegen.top/`，并在测试目录创建文件。它先演示未打开笔记的写入、移动和删除，再打开新建笔记体验编辑器。编辑前会校验本次会话的示例标记；其他笔记不会被一键演示修改。若编辑器尚未就绪、处于非源码模式或当前平台不支持某项能力，结果表会显示具体原因。单项失败不会阻止其他示例。交互弹窗会保留，方便体验表单、更新、替换和关闭。

点击“显示单项测试表单”可继续使用原来的逐项探针。带 ⚠ 的单项操作仍需勾选确认，单项删除仍需输入 `DELETE`。宿主导航、设置变化与故意异常保留为可点击入口，不会在一键演示中反复切换页面或故意中断宿主。

## 推荐测试顺序

- **基础能力**：插件信息 → 日历 → 六种设置 → 保存、读取、删除两种存储。保存后重启插件再读取，检查持久化；切换工作区，比较设备存储与工作区存储。
- **笔记操作**：创建测试笔记 → 读取 → 追加 → 过期版本保护 → 移动 → 打开。打开后先关闭所有引用该文件的标签页、分栏和独立窗口，再运行写入、移动或删除。也可以使用 `write/create` 路径新建另一个测试笔记。
- **列表与搜索**：创建多篇测试笔记，将数量设为 1，运行递归列表和下一页；用正文中的文本搜索。没有下一页会明确提示。搜索只包含已保存的 Markdown。
- **附件**：创建 TXT 附件 → 读取，检查路径、字节数和 Base64。内容固定为 `NoteGen Plugin Playground` 加换行。
- **编辑器**：从主面板底部树打开左侧栏或右侧栏，在侧栏中运行测试，同时保持 Markdown 笔记处于活动状态。依次读取快照与选区、光标插入、替换选区；切到源码模式测试首尾原子批量编辑与 UTF-16 选区定位。修改直接作用于当前笔记，可使用宿主撤销操作恢复。
- **网络**：手动运行一次 HTTPS GET。只访问 `https://notegen.top/`，不发送笔记、表单文本或凭据；显示 HTTP 状态、响应头与前 1500 个字符。HTTP 4xx／5xx 也可能是已完成的网络调用，请根据返回状态判断服务结果。
- **界面**：通知、状态栏显示／隐藏／忙碌 → 弹窗校验、更新、替换、程序关闭 → 视图打开、聚焦、状态查询、关闭 → 宿主搜索、设置与插件设置导航。

新建操作每次使用新路径，只有明确创建成功的笔记才会成为当前测试笔记。移动、追加、删除只作用于它。“只读示例文件”设置仅影响读取操作。重启或切换工作区后，插件不会接管旧测试文件。

## 表单与事件

主面板和两侧栏各有独立表单。表单包含文本、多行文本、数字、选择、复选框、条件字段与禁用字段。删除确认仅在选择删除操作时显示。输入变化使用防抖回调和 `expectedForm` 防止旧响应覆盖新输入；“重置表单”通过 `resetKey` 清空值与反馈。

弹窗中的名称至少需要两个字符，过短时显示字段错误；勾选“显示详细内容”后可填写备注。隐藏和禁用字段不参与提交。合法提交会关闭弹窗并显示结果。更新弹窗保留宿主支持保留的表单状态；替换弹窗创建新的交互实例。

事件记录覆盖：设置、工作区、笔记、活动编辑器、编辑内容、视图状态、弹窗关闭、表单变化和插件激活。记录有数量上限，只驻留内存；不会把编辑正文持久化到日志。禁用插件会取消订阅，重新启用后开始新会话。工作区切换会清空旧运行结果、列表游标和测试路径。

## 错误与平台差异

| 场景 | 预期结果 |
| --- | --- |
| 未授予所需权限 | `PermissionDenied`，其他功能仍可使用 |
| 文件仍在任一编辑器中打开 | 写入、移动、删除返回 `EditorBusy` |
| 运行过期版本保护 | 先追加 revision 标记，再确认旧 revision 返回 `StaleRevision`，且拒绝后内容未改变 |
| 错误时区探针 | 收到 `InvalidTimeZone` 才判定成功 |
| 非法路径探针 | 读取 `../outside.md` 收到 `InvalidPath` 才判定成功；无权限时可能先返回权限错误 |
| 非源码模式批量编辑／定位 | 插件提示切换源码模式 |
| 移动端或不支持的宿主表面 | 可能返回 `UnavailableOnPlatform`；部分侧栏可能不展示 |
| 故意抛出异常命令 | 通过命令面板运行“实验室：故意抛出异常”，观察宿主错误提示及后续命令是否仍可用 |

清单声明桌面、iOS、Android，便于在各端验证能力差异，不表示每项 API 在每个平台都可用。删除目前仅支持桌面系统废纸篓；编辑器独立窗口、只读文件、配额、断网或超时等限制由宿主执行。跨平台行为尚需在实际设备中验收。

运行成功计数只表示这 32 项调用／探针的本次结果。签名、完整性、安装升级、兼容性、工作线程隔离、看门狗与运行配额是宿主／SDK 的测试范围，不能由已加载的普通插件完整验证。本示例不会自动触发死循环或批量耗尽配额。

## 清理

“清空运行记录”仅清空结果与覆盖记录；“删除示例存储键”只删除本插件两种存储中的 `sample` 键。笔记删除只删除当前测试笔记。其他生成文件保留，方便检查；请在文件管理器中手动清理测试目录。公开附件 API 暂无删除能力。
