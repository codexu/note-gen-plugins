# 韩语语言包使用说明

这个独立插件为 NoteGen 增加 **한국어** 界面语言，不会移除系统内置语言。

## 切换为韩语

1. 安装韩语语言包，在当前工作空间启用它。
2. 打开「设置 → 通用设置 → 界面设置 → 语言」。
3. 选择 **한국어**，界面文字会随宿主语言刷新。

本包无需权限，不读取笔记，不联网，也不翻译笔记正文或 AI 的回答。需要支持语言资源扩展协议 `0.1.2` 的 NoteGen 桌面版本。仅有本源码目录不能直接代表已发布的可安装包；开发导入需要先构建 `.notegen/package`，并开启宿主开发者模式。

## 恢复原语言

在同一语言设置中选择任意内置语言即可。也可以在插件管理中停用或卸载本包。没有其他韩语提供者时，宿主恢复显示默认简体中文，同时保留已保存的韩语偏好，重新启用后可以恢复。笔记和其他语言不受影响。

## 部分文字仍显示中文

宿主新增加的字段会回退到内置中文。当前两个 Mermaid ER 代码示例沿用宿主模板，其他代码、产品名、文件路径及命令不会强行翻译。第三方插件有自己的界面翻译资源，不一定随本包变为韩语。

若 **한국어** 没有出现，检查本包是否在当前工作空间启用，以及宿主是否支持新的语言资源协议。多个包都提供韩语时，重叠字段由插件 ID 字典序靠前的包优先提供。
