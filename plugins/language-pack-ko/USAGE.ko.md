# 한국어 언어 팩 사용 안내

이 독립 플러그인은 NoteGen의 언어 목록에 **한국어**를 추가합니다. 기본 제공 언어는 그대로 유지됩니다.

## 한국어로 변경하기

1. 언어 팩을 설치하고 현재 작업 공간에서 활성화하세요.
2. 설정 → 일반 설정 → 인터페이스 설정 → 언어로 이동하세요.
3. **한국어**를 선택하세요. 앱이 인터페이스 문구를 갱신합니다.

이 언어 팩은 별도 권한이 필요하지 않습니다. 노트를 읽거나 네트워크에 접속하지 않으며, 노트 본문이나 AI 답변을 번역하지 않습니다. 언어 리소스 프로토콜 `0.1.2`를 지원하는 NoteGen 데스크톱 버전이 필요합니다. 소스 폴더 자체는 배포된 설치 패키지가 아닙니다. 개발용으로 가져오려면 `.notegen/package`를 빌드하고 개발자 모드를 켜야 합니다.

## 원래 언어로 돌아가기

같은 설정 화면에서 기본 제공 언어를 선택하세요. 플러그인 관리에서 이 언어 팩을 비활성화하거나 제거할 수도 있습니다. 다른 한국어 제공 플러그인이 없으면 앱은 기본 언어인 중국어 간체를 표시합니다. 저장된 한국어 설정은 유지되므로 다시 활성화하면 복원할 수 있습니다. 노트와 다른 언어에는 영향을 주지 않습니다.

## 일부 문구가 중국어로 표시되는 경우

앱에 새로 추가된 번역 항목은 기본 중국어 문구로 표시될 수 있습니다. Mermaid ER 코드 예제 두 개는 현재 앱의 원본을 사용합니다. 코드, 제품 이름, 파일 경로와 명령은 원래 표기를 유지합니다. 다른 플러그인은 별도의 번역을 사용하므로 한국어가 제공되지 않을 수 있습니다.

언어 목록에 **한국어**가 없다면 현재 작업 공간에서 이 팩이 활성화되어 있는지, 앱이 언어 리소스 프로토콜을 지원하는지 확인하세요. 한국어를 제공하는 팩이 여러 개라면 중복 항목에는 플러그인 ID의 사전순으로 앞선 팩이 우선 적용됩니다.
