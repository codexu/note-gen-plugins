# 한국어 언어 팩 사용 방법

1. 현재 작업 공간에 언어 팩을 설치하고 활성화하세요.
2. 설정 → 일반 설정 → 인터페이스 설정 → 언어를 여세요.
3. **한국어**를 선택하면 인터페이스가 갱신됩니다.

간체 중국어와 영어는 기본 제공됩니다. 다른 언어는 해당 플러그인을 활성화해야 합니다. 이 플러그인은 데스크톱 전용이며 추가 권한을 요구하거나 노트 본문을 읽고 번역하지 않습니다.

비활성화하거나 제거하면 같은 언어의 다른 제공자가 없는 경우 기본 중국어로 표시됩니다. 한국어 선택은 보존되므로 다시 활성화하면 복원됩니다.

현재 호스트의 5,168개 항목을 지원합니다. 5,166개 문구를 제공하며 ER 코드 템플릿 두 개는 호스트 값을 사용합니다. 누락된 문구는 호스트의 대체 언어 규칙을 따릅니다. 코드와 경로, 제품명은 원문을 유지할 수 있습니다. 다른 플러그인의 문구는 각 플러그인에서 관리합니다.

출시된 NoteGen 0.39.1 이상을 지원하며, 아직 출시되지 않은 템플릿 수정은 필요하지 않습니다. 호환성 및 개발 가져오기 방법은 [영문 안내](README.en.md)를 참고하세요. 이번 개정의 실행 검증과 한국어 모어 사용자 검토는 아직 완료되지 않았습니다.
