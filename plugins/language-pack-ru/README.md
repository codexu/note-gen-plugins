# 俄语语言包

[English](README.en.md) · [中文使用说明](USAGE.zh-CN.md) · [English usage](USAGE.md)

为 NoteGen 添加 **Русский** 界面。当前版本 `0.1.1`，通过声明式语言资源提供翻译，无运行脚本、权限、网络请求或运行时依赖。

## 安装与切换

安装并在当前工作空间启用插件后，打开「设置 → 通用设置 → 界面设置 → 语言」，选择 **Русский**。迁移后的新版 NoteGen 仅内置简体中文和英语；NoteGen 0.39.1 保留原有内置语言，语言包可补充对应译文。

最低支持已发布的 NoteGen `0.39.1`。两项 Mermaid ER 代码模板继承宿主原值，不要求尚未发布的模板校验修复。插件语言资源协议沿用 `0.1.2`，当前仅支持桌面端。文件中保留移动端消息，不表示移动端可安装本插件。

## 翻译范围与基线

`messages/ru.json` 覆盖当前宿主的 **5,168 个字段：直接提供 5,166 项，其余两项 ER 代码模板继承宿主**，公共消息合并在 `common` 下。包含设置、记录、标签、AI 对话、编辑器、文件、同步、画布、插件管理及窗口界面。基线提交、源文件哈希和审阅状态见 [translation-baseline.json](translation-baseline.json)。

保留原有译文，新增普通文案由本地 Argos en-ru 1.9 辅助起稿；参数文案、常用术语和关键数据操作提示另行修订。 2026-11-01 已通过字段覆盖、ICU 参数、宿主注册与回退逻辑、插件构建及打包检查，主应用生产构建也已通过。桌面界面验收与母语审校仍待完成。

- ICU 参数名和复数结构保持兼容；计数提示使用目标语言表达。
- Mermaid 模板保留可执行语法。`settings.editor.mermaid.templates.er` 和 `editor.mermaid.templates.er` 不在包中重复声明，直接继承宿主代码，避免旧版 ICU 校验将 `o{` 误当参数；这两项不是待翻译文案。
- 图片保存路径中的 `__PATH__` 是应用实际使用的替换标记，不能改成 ICU 参数。
- 缺失字段按宿主规则回退；迁移后的新版优先回退到英语，再回退到简体中文。第三方插件文案由各插件维护。
- 不读取或翻译笔记正文，不改变 AI 模型输出语言，不随包分发翻译模型或起稿工具。

## 生命周期

停用或卸载后，若宿主仍内置该语言或有其他提供者，则继续使用该语言；否则语言选项消失，界面暂用默认简体中文；原语言偏好仍被保存，再次启用后恢复。重启和工作空间切换也遵循当前工作空间的插件启用状态。相同语言的多个提供者重叠时，插件 ID 字典序靠前者优先。

## 开发导入

在插件仓库运行以下命令（本次测试阶段已执行）：

```bash
pnpm --filter @notegen/plugin-language-pack-ru build
pnpm --filter @notegen/plugin-language-pack-ru validate
pnpm --filter @notegen/plugin-language-pack-ru run plugin:pack
```

在 NoteGen 开启开发者模式后导入生成的 `.notegen/package`。源码目录不是已发布安装包。市场登记只准备源码元数据，不代表完成打包、签名或发布。
