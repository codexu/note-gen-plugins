# 俄语语言包

[English](README.en.md) · [Русский: инструкция](USAGE.ru.md)

NoteGen 独立俄语界面语言包。安装并启用后，在「设置 → 通用设置 → 界面设置 → 语言」选择 **Русский**。界面消息随选择刷新，已有内置语言仍然可用。

当前为 **0.1.0 首版**。译文采用本地机器翻译辅助起稿，并修订常用界面、参数消息和技术术语；仍需俄语母语审校及桌面端使用验收。

## 翻译范围与维护

`messages/ru.json` 使用宿主嵌套消息结构，公共消息放在 `common` 下。覆盖通用操作、设置、插件管理、编辑器、记录、AI 对话、文件管理、同步、知识库、画布和窗口；文件中也保留移动端消息，但当前插件资源仅在桌面端注册。插件自身的名称和介绍提供英文、简体中文与俄文，供宿主按当前语言显示。

基线为宿主已提交的 `3284534d3e5ea12abf0c7de5981d4cca2c26f62c`，不包含主目录未提交变更。共 4,390 个字符串字段，本包提供 4,388 个。提交、日期、源文件 SHA-256、例外与审阅状态记录在 [translation-baseline.json](translation-baseline.json)。字段覆盖不等于运行验收或逐条母语审校通过。

- 俄语计数文案采用 ICU `one` / `few` / `many` / `other` 分支，或使用「Количество: {count}」一类不依赖词尾变化的表达。ICU 参数名和代码标识不翻译。
- `editor.slashCommand.imageUpload.savePath` 保留宿主实际使用的 `__PATH__` 替换标记。
- 不重复声明 `settings.editor.mermaid.templates.er` 和 `editor.mermaid.templates.er`。宿主校验会把中文基线中的字面量 `o{` 当作 ICU 参数并报错，因此这两处 ER 模板回退至宿主。其余 Mermaid 代码模板保留原始英文示例和可执行语法。
- 新增或遗漏的宿主字段回退到内置简体中文。第三方插件自身的文案由各插件维护，本包不为其提供翻译。
- 模型、生成缓存和翻译脚本只用于本地起稿，不随插件分发；使用插件无需模型、网络或额外运行依赖。

更新译文时，应以宿主中文消息的结构和参数为准，参考同一提交的英文消息；同步更新基线记录，保留未审校和回退范围，不以英文副本冒充俄语覆盖。

## 构建与开发导入

本包依赖工作区的 `@notegen/plugin-cli`，沿用仓库 `.sdk` 配置。仓库的 `plugins/*` 已覆盖本目录。在插件仓库运行：

```bash
pnpm --filter @notegen/plugin-language-pack-ru build
pnpm --filter @notegen/plugin-language-pack-ru validate
pnpm --filter @notegen/plugin-language-pack-ru run plugin:pack
```

开发导入使用生成的 `.notegen/package`，需要在 NoteGen 中开启开发者模式；源码目录本身不是可安装包。最低版本号本身不代表旧版宿主必然具备所需资源协议。

## 生命周期与验收

语言随当前工作空间中的启用状态注册。停用或卸载后，若没有其他俄语提供者，宿主显示默认简体中文并保留已保存的 `ru` 选择；再次启用时可恢复俄语。相同语言有多个提供者时，插件 ID 字典序靠前者优先。插件不会翻译、读取或修改笔记正文，也不会改变 AI 模型的输出语言。

待完成的人工验收：

1. 构建后导入并启用，在设置中选择 Русский，检查导航、保存/取消、编辑器与插件设置。
2. 在窄窗口、侧栏和弹窗中检查俄语长文案的换行及截断。
3. 检查计数 1、2、5、11、21、22、25 的俄语词形，以及路径、名称、错误消息的动态插值。
4. 切换内置语言、重新选择俄语；重启、切换工作空间、停用、卸载和重新启用后检查语言恢复。
5. 检查缺失字段回退、Mermaid 示例、图片保存路径和多个俄语提供者的优先级。
6. 请俄语母语使用者审阅译文，尤其是权限说明、删除/同步提示及 AI 指令，并持续修订。

以上人工验收仍待完成。移动端运行不在本包支持范围内。
