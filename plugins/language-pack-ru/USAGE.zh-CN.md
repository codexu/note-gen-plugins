# 使用俄语语言包

本插件为 NoteGen 桌面端添加 **Русский**，保留所有内置语言。最低需要 NoteGen 0.37.1，且宿主必须支持语言资源协议 0.1.2。

## 切换为俄语

1. 安装语言包，并在当前工作空间启用它。
2. 打开「设置 → 通用设置 → 界面设置 → 语言」。
3. 选择 **Русский**，界面消息随选择刷新。

可从插件市场安装；若使用开发导入，需先构建 `.notegen/package`，并启用 NoteGen 开发者模式。

## 恢复其他语言

在同一设置页面选择内置语言，或在插件管理中停用、卸载本包。若没有其他俄语提供者，宿主回到默认简体中文；已保存的俄语选择会保留，重新启用后可恢复。笔记内容不受影响。

## 使用边界

- 无需权限，不读取笔记、不联网，不翻译笔记正文或 AI 回复。
- 某些新增宿主字段回退为中文；两个 Mermaid ER 模板沿用宿主，其余代码示例保留英文语法。其他插件未提供俄语的文案不在本包范围内。
- 找不到 Русский 时，检查当前工作空间的启用状态和宿主资源协议支持。多个俄语包重叠时，插件 ID 字典序靠前者优先。
- 译文经过机器辅助起稿及常用文案修订，尚待俄语母语审校和真实桌面验收，不支持移动端加载。
