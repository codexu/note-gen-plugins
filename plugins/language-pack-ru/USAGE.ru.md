# Использование русского языкового пакета

1. Установите пакет и включите его в текущей рабочей области.
2. Откройте настройки → общие настройки → настройки интерфейса → язык.
3. Выберите **Русский**. Тексты интерфейса обновятся.

Упрощённый китайский и английский встроены. Для других языков нужны соответствующие включённые плагины. Пакет предназначен только для настольной версии, не требует дополнительных разрешений и не читает и не переводит содержимое заметок.

При отключении или удалении пакета интерфейс временно вернётся к китайскому, если другого поставщика русского языка нет. Выбор языка сохраняется и восстанавливается после повторного включения.

Пакет содержит 5 168 полей текущего приложения. Будущие отсутствующие переводы заменяются английскими, затем китайскими. Код, пути и названия продуктов могут оставаться без перевода. Другие плагины поддерживают свои переводы самостоятельно.

Сборка приложения для разработки должна содержать исправление обработки неизменённых шаблонов кода. Совместимость и импорт описаны в [английском руководстве](README.en.md). Проверка работы и редактура носителем русского языка для этой редакции ещё не выполнены.
