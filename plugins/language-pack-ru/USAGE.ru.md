# Русский языковой пакет

Плагин добавляет **Русский** в список языков интерфейса NoteGen на компьютере. Все встроенные языки остаются доступными. Требуется NoteGen 0.37.1 или новее с поддержкой протокола языковых ресурсов 0.1.2.

## Как включить русский язык

1. Установите пакет и включите его в текущем рабочем пространстве.
2. Откройте Settings → General Settings → Interface Settings → Language.
3. Выберите **Русский**. Текст интерфейса обновится.

После переключения этот путь называется «Настройки → Общие настройки → Настройки интерфейса → Язык».

Пакет можно установить через каталог плагинов. Для импорта в режиме разработчика сначала соберите `.notegen/package` и включите Developer Mode в NoteGen.

## Как вернуть другой язык

Выберите встроенный язык на той же странице или отключите либо удалите пакет в разделе плагинов. Если других поставщиков русского языка нет, интерфейс вернётся к китайскому языку по умолчанию. Выбор русского сохранится для повторного включения пакета. Содержимое заметок не изменится.

## Ограничения

Пакет не запрашивает разрешения, не читает заметки и не обращается к сети. Он переводит интерфейс, но не тексты заметок и не ответы ИИ.

Новые строки приложения могут отображаться на китайском. Два примера ER-диаграмм Mermaid наследуются от приложения; в остальных примерах кода сохранён английский синтаксис. Переводы сторонних плагинов поддерживают их авторы.

Если в списке нет **Русский**, проверьте, включён ли пакет в текущем рабочем пространстве и поддерживает ли приложение протокол языковых ресурсов. При нескольких пакетах русского языка приоритет имеет плагин, чей ID идёт раньше в лексикографическом порядке.

Перевод подготовлен с помощью локального машинного перевода; основные команды, термины и сообщения с параметрами дополнительно отредактированы. Проверка носителем русского языка и проверка работы в приложении пока не проведены. Загрузка пакета на мобильных устройствах не поддерживается.
