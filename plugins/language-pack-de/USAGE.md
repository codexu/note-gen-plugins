# Using the German Language Pack

1. Install and enable the pack in the current workspace.
2. Open Settings → General Settings → Interface Settings → Language.
3. Choose **Deutsch**. NoteGen refreshes the interface messages.

Simplified Chinese and English are built in. Other languages require their enabled language packs. Desktop only; no extra permissions are required. This pack does not read or translate note content.

Select another language to switch away. Disabling or uninstalling the pack temporarily restores Simplified Chinese if no other provider remains, while retaining your language preference for re-enablement.

If the language is missing, check activation in the current workspace. A development host must include the unchanged-literal template fix; see [README](README.en.md) for version and compatibility details. Source preparation is not packaging, signing or publication.
