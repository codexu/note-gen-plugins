# Using the German Language Pack

1. Install and enable the pack in the current workspace.
2. Open Settings → General Settings → Interface Settings → Language.
3. Choose **Deutsch**. NoteGen refreshes the interface messages.

Simplified Chinese and English are built in. Hosts after the migration use packs for other languages; older hosts retain their built-in languages. Desktop only; no extra permissions are required. This pack does not read or translate note content.

Select another language to switch away. Disabling or uninstalling retains any built-in language or other provider; otherwise it temporarily restores Simplified Chinese while saving your language preference for re-enablement.

If the language is missing, check activation in the current workspace. Released NoteGen 0.39.1 is supported; see [README](README.en.md) for version and compatibility details. Source preparation is not packaging, signing or publication.
