# 使用日语语言包

1. 安装并在当前工作空间启用插件。
2. 打开「设置 → 通用设置 → 界面设置 → 语言」。
3. 选择 **日本語**，界面将刷新为该语言。

简体中文和英语内置可用，其他语言需要启用对应语言插件。本插件仅支持桌面端，不需要额外权限，也不会读取或翻译笔记正文。

选择其他语言即可切换。停用或卸载后，如果没有其他同语言提供者，界面暂用简体中文并保留原语言偏好，再次启用后恢复。

如果找不到语言选项，请检查当前工作空间是否启用本插件。使用开发构建时，宿主须包含本次原样代码模板校验修复；最低版本和兼容说明见 [README](README.md)。源码尚未打包、签名或发布。

当前文案按 5,168 个宿主字段补齐。后续缺失字段先显示英语，再回退中文；代码、路径和产品名可能保留原样。其他插件自身的翻译由各插件维护。本次自动检查和构建已通过；桌面界面验收与母语审校仍待完成。
