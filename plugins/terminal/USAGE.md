# Using Terminal

1. Install and enable the desktop Terminal plugin, and review the `terminal.open` permission.
2. Choose Terminal from the editor tab bar's `+` menu, or run the Open terminal plugin command.
3. Type commands in the terminal. It starts in the current NoteGen workspace. Tools such as Claude Code must already be installed and authenticated on the computer.
4. Right-click the Terminal tab and choose Restart Terminal to start a new shell. Closing the tab or disabling the plugin also ends its session.

Commands run as the current system user and may change or delete any accessible file. The plugin is unavailable on mobile and web. This version does not persist terminal output or sessions.
