# 终端

NoteGen 官方桌面插件。在编辑器的独立标签页中运行交互式命令行，默认进入当前工作区。终端界面和 xterm 由插件提供；NoteGen 只提供经过权限检查的 PTY 能力。终端会跟随 NoteGen 的主题、字体、缩放和语言变化。

插件需要 NoteGen 0.38.0 或更新版本。启用时需确认 `terminal.open` 权限；命令以当前系统用户身份运行，可访问 NoteGen 工作区以外的文件。关闭标签、切换工作区或停用插件会结束会话，重启应用后不会恢复。参见[使用说明](USAGE.zh-CN.md)和[英文介绍](README.en.md)。

## 本地开发

在 `note-gen-plugins` 仓库执行 `pnpm dev:terminal`。它会监听 SDK 与终端源码，并自动更新 `.notegen/package`，无需每次手动构建。另行启动 NoteGen 桌面开发环境，开启开发者模式，首次导入本插件目录并确认权限。此后修改会自动重新加载；新增或扩大的权限仍需重新确认。重新加载会结束当前 shell 会话。
