# 文档预览

本插件仅在支持插件 API 0.1.2 的 NoteGen 桌面版中使用。安装完整插件包后启用，在授权对话框中选择“整个工作区”，之后可从工作区文件树打开任意 PDF、DOCX、XLSX 或 PPTX，无需逐个文件授权。用户无需安装 npm 依赖，也不需要安装 LibreOffice。

所有文档在本地隔离预览容器中处理，不上传到外部服务，不修改原文件。

## PDF

使用左右箭头或输入页码翻页，点击 −/+ 缩小或放大（25%–300%），也可从缩放下拉框选择比例或“适合宽度”。可以拖动选择页面中的文本。文件名使用 NoteGen 标签页显示，预览区不重复显示。

输入关键词后点击放大镜或按回车，结果数量及上下匹配箭头会在搜索后显示；再次按回车跳到下个匹配，Shift+回车跳到上个匹配。点击 × 或按 Esc 清除搜索。“停止”仅在搜索过程中显示，停止后保留部分结果。图标悬停可查看功能说明。搜索忽略英文大小写，不跨页匹配；多栏、连字和断词取决于文档内部文本顺序。扫描 PDF 没有 OCR 文本时，无法搜索或选择文字。密码 PDF 会要求本地输入密码。

输入文件上限 128 MiB。搜索最多前 2000 页、5000 处或累计 1600 万文本字符，触及限制时会提示结果不完整。不执行 PDF 脚本，不支持 XFA 或交互表单；极大图像受到像素限制。

## Word（DOCX）

滚动查看正文、图片、表格、页眉页脚、脚注和尾注，使用 −/+ 缩放。

这是基于 HTML 的文档排版，字体、浮动对象和分页可能与 Word 不同；不显示修订、批注或嵌入 HTML。不运行宏、不打开文档链接。需精确核对复杂排版时，请在原 Office 应用查看，或先由原应用导出 PDF。

## Excel（XLSX）

从下拉框切换工作表，隐藏表会明确标注。每次展示最多 100 行，可用按钮翻段，或输入起始行跳转。列通过横向滚动浏览，表头显示 A、B 等列名，行号保持固定；翻到下一段行时保留横向位置。长单元格文本省略显示，悬停可查看完整显示值或公式。行列统计显示在 NoteGen 的底部状态栏中；旧版 NoteGen 不支持此接口时，在预览内显示。

此功能是工作表**数据浏览**，不还原打印版式、合并单元格、图表、图片或条件格式。只显示文件保存时的公式结果，不重新计算公式；无缓存结果的公式会明确提示，悬停可查看公式。不运行宏或外部数据连接。

最多浏览前 100000 行与 256 列；超出范围会显示截断提示。显示单元格最多 32768 字符。可拖动选择并复制单元格文本。

## PowerPoint（PPTX）

使用左右箭头、页码输入或预览区域中的方向键、PageUp/PageDown、Home/End 翻页。支持 −/+、10%–300% 缩放和适合窗口。页数显示在 NoteGen 的底部状态栏中，旧版宿主在预览内显示。文件名沿用标签页，预览仅保留工具栏和当前幻灯片。

展示静态文字、图片、形状和表格；复杂 SmartArt、图表、矢量图和字体可能与 PowerPoint 不同。不播放动画、转场或音视频，不打开文档链接；不启用 EMF 内嵌 PDF 回退。最多 300 页，媒体按需读取。

## 未支持的格式与失败处理

暂不支持老格式 DOC/XLS/PPT 和宏格式 DOCM/XLSM/PPTM，插件不会接管它们。不以文字提取或 Markdown 替代幻灯片。

DOCX/XLSX/PPTX 文件上限 32 MiB，且压缩包的展开体积、XML 大小、工作表和幻灯片数量受限。加密 Office、ZIP64、损坏或过度压缩的文件会被拒绝。工作表 Worker 解析超过 30 秒会停止。看到错误时可关闭预览、检查读取授权并重新打开；大型/复杂 DOCX 或 PPTX 排版可能使容器卡顿，关闭预览释放资源，必要时使用 Office 应用。

关闭文件、禁用插件或切换工作区会释放预览。界面语言通过宿主传入的 locale 跟随 NoteGen；未支持的语言、未传入该字段的旧宿主回退英文。切换 NoteGen 语言会重新加载预览。颜色仍跟随系统深浅色偏好。
