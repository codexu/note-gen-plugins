# 动态模板

用 Markdown 模板生成会议纪要、日报和读书笔记，也可以读取自己的模板文件。

## 开始使用

1. 在插件设置中配置「模板文件夹」（默认 `Templates`）和「新笔记文件夹」（默认 `Notes`），均为工作区相对路径。目录不能使用 `.`、`..`、隐藏目录、绝对路径或路径变量。
2. 授权 `notes.read`、`notes.list` 访问模板目录；新笔记目录通过设置绑定 `notes.create`、`notes.open`。修改模板目录后也要调整这两项读取授权。宿主只支持一个自动目录权限绑定，因此模板目录不会自动修改授权。
3. 执行「从模板新建笔记」，或在 Markdown **源码模式**中放置光标后执行「插入动态模板」。也可通过文件或编辑器右键菜单进入。
4. 选择内置模板或目录里的 `.md` 文件，填写字段，检查预览，勾选确认后应用。新笔记标题不含 `.md`；输出到配置目录。

模板目录递归分页读取，每页 50 个文件；内置模板每页都可选。读取的是已经保存的 Markdown，不包括编辑器尚未保存的模板修改。内置模板根据插件界面语言选择中文或英文，不会自动复制到工作区。可以从项目的 `templates/zh-CN` 或 `templates/en` 复制示例再自行编辑。

## 两种自定义方式

在插件专属设置页可以查看说明并点击「创建模板」；选择模板的窗口也提供同一按钮。

- **手写文件**：将 Markdown 模板保存到配置目录，按下文语法自行编写变量和字段声明。
- **创建向导**：填写模板文件名和 Markdown 正文。正文中写入 `{{field.topic}}` 等自定义变量后，下一步会自动列出字段，让你选择显示名称、单行/多行/日期类型、必填和默认值，无需手写 JSON。检查生成内容后保存；也可从预览返回编辑。

两种方式都保存为普通 `.md` 文件，之后可以直接编辑。向导正文最多 16,000 个字符，支持最多 20 个自定义字段，每页配置 6 个；手写文件仍适用原有 64 KiB 限制。没有自定义字段时，向导直接保存普通 Markdown。

创建向导需要额外启用可选的 `notes.write` 权限，并仅授权到模板文件夹。该 API 的权限本身可写文件，但本插件只发送新建请求，不提供覆盖已有文件所需的修订号，因此同名文件会被宿主拒绝。不会自动打开新模板，也不会额外扩大打开权限。保存成功后，重新打开模板选择窗口即可选择新文件。取消、工作区切换会使未提交草稿失效；已发出的写入不能撤销。

## 模板语法 v1

正文支持以下变量，允许花括号内侧的空格：

| 变量 | 含义 |
| --- | --- |
| `{{date}}` | 预览时的本地日期 `YYYY-MM-DD` |
| `{{time}}` | 宿主返回的本地时间部分 |
| `{{datetime}}` | 宿主返回的完整本地日期时间 |
| `{{title}}` | 当前笔记文件名去掉 `.md`，或填写的新笔记标题 |
| `{{selection}}` | 打开命令时捕获的选中文本；没有选区时为空 |
| `{{field.topic}}` | 自定义字段 `topic` 的填写内容 |

日期时间由公开的 `calendar.resolveDay` 接口按系统时区、午夜日界线解析，并固定在预览时。标题在宿主没有提供当前文件路径时为空。

自定义字段只通过**文件开头**的 JSON 注释声明：

```markdown
<!-- notegen-template
{
  "fields": [
    { "id": "topic", "label": "主题", "type": "text", "required": true },
    { "id": "summary", "label": "摘要", "type": "textarea", "default": "" },
    { "id": "due", "label": "截止日期", "type": "date" }
  ]
}
-->
# {{title}}

日期：{{date}}
主题：{{field.topic}}
摘要：{{field.summary}}
截止：{{field.due}}

{{selection}}
```

字段类型支持 `text`、`textarea`、`date`，默认值必须是字符串。最多 20 个字段，每个值最多 4,000 个字符。字段 ID 使用英文字母开头，后接字母、数字或下划线，最长 40 个字符，不能重复或使用内置变量名、`constructor`、`prototype`、`__proto__`。未知字段属性、未知变量和不完整变量会报错。模板及渲染结果分别限制为 64 KiB UTF-8。

元数据注释不写入生成内容。替换只进行一遍，字段和选区中的花括号不会再次求值。填写值按原样作为 Markdown 插入，不做 Markdown 转义。普通 Markdown、代码块和 YAML front matter 均原样保留；只有上面明确列出的变量会被替换。v1 不提供字面双花括号转义，请避免在模板固定文字中直接使用 `{{`、`}}`。

## 内容与取消保护

- 插入固定在打开命令时的光标位置；有选区时插入到选区末尾，**不删除原选中文本**。若模板也包含 `{{selection}}`，选中文本会再出现一次。
- 固定 Markdown 位置编辑目前只由宿主的源码模式支持；可视化模式或分段模式请先切换源码模式。
- 应用前检查工作区、编辑器、文档和修订号；内容修改、编辑器切换或输入法组合输入会阻止旧编辑。移动光标不会改变已捕获的插入位置。不会自动重新定位、重试或覆盖内容。
- 同名新笔记使用宿主原子的 `openOrCreate`：打开现有笔记并保留原文，提示未创建新内容。创建后打开失败也会提示路径；先检查文件，不要盲目重试。
- 应用前关闭对话框即取消；切换工作区、停用插件会使旧表单失效。确认后已送达宿主的写入无法撤销；关闭对话框不能回滚已开始的提交。编辑超时或其他提交错误后，先检查目标再重新开始。
- 预览展示 Markdown 源文，超过 12,000 个字符时会明确截断；写入使用完整内容。需要修改字段时，关闭后重新执行命令。

这是独立语法的模板插件，不兼容 Obsidian Templater API，不执行 JavaScript、shell、任意系统命令或网络请求。仅声明编辑器读写、模板读取/列举、笔记新建/打开权限，可选的 notes.write 仅用于创建向导的新建模板请求，不申请删除、移动或网络权限。
