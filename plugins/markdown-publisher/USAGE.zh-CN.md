# 使用公众号排版与导出

1. 在实现 0.1.7 协议的桌面版 NoteGen 中安装插件，并在当前工作区启用。需要当前编辑器读取、剪贴板写入和文件导出权限；附件读取为可选权限。
2. 在 **设置 → 扩展 → 公众号排版与导出** 中选择模板，调整主题色、正文颜色、背景颜色、字体、字号和行距，然后保存。内置模板也可编辑，并能恢复默认值。
3. 点击「新建模板」，填写名称、选择基础风格、调整参数即可保存。自定义 CSS 可留空；需要精细控制时，再填写例如 `.article h2 { color: #2563eb; }`。选中已有模板可继续编辑或删除。每套模板独立保存在本机。
4. 打开 Markdown 笔记，点击底部状态栏的「公众号排版」。右侧抽屉会使用上次选中的模板直接渲染；可切换手机或电脑外框预览，并使用刷新、复制和导出按钮。预览不会改变 Markdown 编辑器样式或笔记正文。
5. 在预览中核对图片与正文。授权后可嵌入目录范围内的小型本地图片；远程图片不会在预览中加载。公式和 Mermaid 暂时保留文本。
6. 点击「复制到公众号」，粘贴到公众号文章编辑器并核对格式与图片；或点击「导出 HTML」使用原生保存对话框。正文修改或切换笔记后，需刷新预览才能复制或导出。

CSS 支持以 `.article` 开头的后代选择器和可移植排版属性。不支持导入、资源 URL、变量、伪类选择器或应用界面选择器。插件不会向发布平台发送笔记内容。

本地开发只需首次导入一次。在插件目录运行 `pnpm dev`，之后保存源码、清单或语言文件会自动构建并重载已启用的插件；构建失败时继续使用上一次可用版本。
