# 公众号排版与导出

NoteGen 官方插件，提供文章模板、自定义正文排版、隔离预览、公众号富文本复制和 HTML 导出。内置清爽专栏、技术手册、纸页长读三种风格鲜明的模板。

最低要求桌面版 **NoteGen 0.38.0**（插件 API 协议 0.1.7），开发依赖 **SDK 0.1.9**。本地开发包由 `pnpm dev` 自动构建和重载。

- 读取当前笔记，包含尚未保存的修改，不改写原 Markdown。
- 三种内置模板可分别调整主题色、正文色、背景色、字体、字号和行距，并可恢复默认值。创建模板时选择基础风格、设置参数即可保存；`.article` 自定义 CSS 为可选的进阶覆盖。
- 预览、剪贴板和 HTML 导出使用同一份排版结果；正文变化后要求刷新。
- 可选附件权限：嵌入授权目录里的小型 PNG/JPEG/GIF/WebP 图片。
- 模板在插件设置页创建和编辑，参数随模板独立保存；底部状态栏显示图标和名称，点击后从右侧打开抽屉，选择模板即刷新排版，并可切换手机或电脑外框预览、复制和导出，不改变 Markdown 编辑器。
- 完整提供英文和简体中文，界面语言跟随 NoteGen，配置保存在本机。

使用步骤见 [中文使用说明](USAGE.zh-CN.md)；另有 [English README](README.en.md) 和 [English usage](USAGE.md)。

本地开发首次导入后，在插件目录运行 `pnpm dev`。保存源码、清单或语言文件时，SDK 会自动构建，已启用的 NoteGen 开发插件会自动重载；无需重新导入。构建失败时保留上一次可用版本，终端会显示错误。停止监听使用 Ctrl+C。

预览不请求远程图片。当前不提供公式/Mermaid 转图片、自动上传图片或直接发布；公众号粘贴效果需要在真实编辑器核对。
