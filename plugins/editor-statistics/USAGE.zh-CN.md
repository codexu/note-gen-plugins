# 编辑器统计

随写随看当前 Markdown 笔记的字符数和预计阅读时间，无需把内容复制到其他工具。

## 开始使用

1. 启用插件，允许读取当前编辑器内容。
2. 打开一篇 Markdown 笔记，状态栏会显示统计结果。
3. 点击统计数字查看详情，也可以使用本页的“立即使用”按钮。

统计会随编辑内容更新。未打开笔记时，请先打开笔记，再查看统计。

## 可以调整什么

在插件设置中选择状态栏显示字符数、单词数、阅读时间或组合指标，
也可以选择字符统计是否包含空白，以及是否统计代码块。

中文、日文、韩文字符会单独统计，不等同于英文单词数。
阅读时间是估算值，不是实际阅读计时。

## 常见问题

- **没有统计数字？** 确认已在当前工作区启用插件、授予编辑器读取权限，并开启插件的状态栏显示设置。
- **数字与其他工具不同？** 检查空白、代码块的设置；不同工具对 Markdown 标记和中英文内容的统计口径可能不同。
- **会修改或上传笔记吗？** 不会。插件只读取当前编辑器内容进行本地计算，不申请写入或网络权限。
