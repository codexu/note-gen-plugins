# Editor Statistics

See character counts and estimated reading time for the Markdown note you are editing.

## Get started

1. Enable the plugin and allow access to the active editor.
2. Open a Markdown note. Statistics appear in the status bar and update as you edit.
3. Click the statistics to view details, or use the action below this guide.

Open a note before requesting statistics if no editor is active.

## Customize

Choose characters, words, reading time, or a combined status-bar display in plugin settings.
You can include or exclude whitespace from character counts and choose whether code blocks are counted.

Chinese, Japanese, and Korean characters are counted separately from English words.
Reading time is an estimate, not a reading timer.

## Troubleshooting

- If nothing appears, check workspace enablement, editor read permission, and the plugin's status-bar visibility setting.
- Counts can differ from other tools because of whitespace, code-block, Markdown, and language-counting rules.
- This plugin calculates locally. It does not request write or network permissions.
