# 关联笔记使用说明

1. 在桌面版 NoteGen 打开一篇已保存的 Markdown 笔记，选中 2–80 个字符的单行词语或短语。
2. 点击选区浮动菜单的「查找关联笔记」。首次使用时，按提示授权编辑器读取和工作区笔记访问。搜索结果会在选中文字附近以紧凑浮层显示。
3. 文字匹配结果先出现，随后“相关”区域会显示加载状态，完成后补充相关笔记。摘要最多显示三行；包含选中文字时会高亮。点击文件名或摘要可跳转到候选文件；点击文件名右侧的「建立链接」则把当前选中文字链接到该候选笔记。候选笔记内容不会被修改。
4. 如果选区或当前笔记已经变化，请重新选中文字再查找。

文字匹配使用已保存的候选文件，并受宿主扫描和结果数量限制。相关搜索使用已索引的 Markdown 文件，可调用 NoteGen 已配置的 Embedding 和重排服务。浮层会标明文字匹配的截断情况。

在「设置 → 插件 → 已安装 → 此插件的设置」中，可调整文字匹配数量（默认 10）、启用相关搜索（默认开启）、最低相关度（默认 0.35）和相关结果数量（默认 5）。最低相关度越高，弱相关结果越少，也可能漏掉有用笔记；它只在插件中筛选结果，NoteGen 的全局 RAG 设置仍在 RAG 设置页调整。设置在下次查找时生效。

在「设置 → 插件 → 已安装 → 此插件的设置 → 界面展示」中，可隐藏浮动菜单入口或结果视图；使用此功能时，两者都需要保持显示。
