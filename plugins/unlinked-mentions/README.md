# 关联笔记

[English](README.en.md)

选中 Markdown 笔记里的词语或短语，点击编辑器浮动菜单中的「查找关联笔记」。浮层会先显示文字匹配结果，再显示“相关”的加载状态和搜索结果。摘要最多三行，包含选中文字时会高亮；点击文件名或摘要可打开候选笔记，点击文件名右侧的「建立链接」可将当前选中文字链接到该候选笔记。

版本 0.1.0，桌面端插件，最低需要 NoteGen 0.38.0 和插件协议 0.1.9。详细步骤见 [使用说明](USAGE.zh-CN.md)。

文字匹配仅搜索授权范围内已保存的 Markdown 文件，由宿主限制为前 200 个文件、最多 16 MiB 扫描内容和 100 条命中。相关搜索仅检索授权范围内已索引的 Markdown 笔记，可使用 NoteGen 已配置的 Embedding 与重排服务；不可用时会回退到本地关键词检索。插件设置可调整文字匹配数量（1–15）、是否启用相关搜索、最低相关度（0–1）和相关结果数量（1–10）。最低相关度只筛选宿主返回的分数，不改变全局 RAG 检索和索引设置。文字匹配被截断时会提示。

候选笔记中的原文不会被修改。当前笔记已链接的候选项不会重复出现；建立链接前会核对当前选区和文档版本，避免把链接写到变化后的内容中。

## 权限

| 权限 | 用途 |
| --- | --- |
| `editor.read` | 获取选区和当前笔记路径 |
| `editor.write` | 点击「建立链接」后修改当前选中文字 |
| `notes.list`、`notes.read` | 搜索并读取候选笔记摘要 |
| `notes.open` | 仅在用户点击候选笔记路径后打开文件 |

本功能使用插件协议 0.1.9 的 `editor/selection-panel` 视图入口。
