# 使用 Iconize

启用插件后打开“设置 → 扩展 → Iconize”，或右键文件/文件夹、标签页选择“图标：指定图标”。右键操作会自动填入路径。首次启用没有预设规则。

1. 选择“指定文件或文件夹”、对象类型，并填写工作区相对路径，例如 `Notes/工作.md` 或 `Projects`。
2. 选择内置图标；如需 Emoji，在 Emoji 栏输入 `📚`、`📝` 或 `🟦`。非空 Emoji 会覆盖内置图标选择；清空它可恢复使用内置图标。
3. 点击“添加规则”。文件树和标签页通过同一公开接口更新。

“扩展名规则”使用 `md`、`pdf` 等扩展名，也接受 `.MD` 并转为 `md`；对象必须是文件。“默认图标”可分别设置文件和文件夹，目标留空。“固定路径规则”只匹配完整路径，文件夹规则不会影响其子文件。暂不支持通配符。

优先级依次为指定图标、固定路径、扩展名、默认图标。同组中第一条命中的启用规则生效。拖拽可调整同组优先级，跨组拖拽后仍按固定优先级显示。最多 100 条规则。

列表每项菜单可编辑、启用/停用或删除规则。编辑后点击“更新规则”；修改目标路径即可手动重新绑定。点击“新增规则”退出当前编辑。若图标未更新，使用“重新载入并应用”；这个动作会放弃尚未保存的表单内容。

## 颜色与移动

当前公开接口没有颜色字段，不能单独给内置图标染色。可用 🟥 🟧 🟨 🟩 🟦 🟪 等自带颜色的 Emoji；显示样式由操作系统决定。

默认不跟随移动。若需要，在文件指定规则中打开跟随选项，并在插件权限中授予可选的笔记列表权限。插件只接收授权范围内的笔记事件，不读取正文。宿主报告可观察的笔记移动后，指定规则迁移到新路径；报告删除时移除该规则。目标已有规则时，仍按列表顺序决定哪条优先。

文件夹、附件、外部重命名、插件关闭期间的变更或授权范围外的移动不保证能跟随。文件夹不显示跟随选项，请手动编辑目标。固定路径、扩展名和默认规则永远不会被自动迁移。

## 工作区与恢复

配置按工作区独立保存。停用插件会恢复宿主或其他插件图标，重新启用会恢复已保存规则。清理图标由宿主完成，无需手工撤销文件修改。

其他已打开窗口需重新载入规则或重启插件；避免同时在多个窗口编辑。若另一图标插件先匹配，宿主按插件 ID 排序选择它，可停用重叠规则或该提供者。保存后若应用失败，先重新载入并应用；存储可能已经成功。

相对路径必须满足 SDK 安全路径限制。绝对路径、通配符、保留路径和部分文件类型不接受单独指定。若权限未授予，图标本身仍可使用，但自动跟随不可用。
