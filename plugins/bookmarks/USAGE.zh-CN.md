# Bookmarks

版本 0.1.0，需要 NoteGen 0.37.0 及插件 API 0.1.1。

列表显示文件名和正文摘要，摘要跳过一级标题。点击文件打开，直接拖拽文件行排序，右键移除收藏，不会删除笔记。顶部右侧加号收藏当前文档，也支持文件和标签页右键收藏。

可在插件设置中修改侧栏显示名称，留空恢复默认。

## 界面展示

在支持界面展示设置的 NoteGen 中，打开「设置 → 插件 → 已安装 → 此插件的设置 → 界面展示」，可分别控制：左侧边栏 Tab、文件右键菜单、编辑器右键菜单、标签页右键菜单、编辑器工具栏。默认展示，修改立即生效，按当前设备保存并适用于此设备上的所有工作区。

隐藏入口不会停用插件或删除数据，仍可从命令面板执行命令。隐藏侧栏或编辑器 Tab 后，插件不会自动重新打开该视图；需要查看时先重新开启对应展示开关。
