# Bookmarks

[简体中文](README.md)

Bookmark notes with file names, content previews and modification times in local time. Drag rows to reorder them and use the context menu to remove bookmarks. Modification times come from saved files; if the host does not provide them, the plugin shows “Update time unavailable”.

Version 0.1.2. See the [usage guide](USAGE.md).

## Display settings

In supported NoteGen versions, open Settings → Plugins → Installed → this plugin's settings → Display. Control the left sidebar tab, file context menu, editor context menu, tab context menu and editor toolbar separately. Entries are visible by default. Changes apply immediately, are saved on this device and affect all workspaces on it.

Hiding an entry does not disable the plugin or delete data. Commands remain available in the command palette. Hidden sidebar or editor tabs are not reopened automatically; enable the corresponding display option to show them again.
