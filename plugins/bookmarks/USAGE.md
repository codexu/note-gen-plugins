# Bookmarks

Version 0.1.0 requires NoteGen 0.37.0 and plugin API 0.1.1.

Each item shows the filename and a body excerpt excluding level-one headings. Click to open, drag the entire row to reorder, or right-click to remove the bookmark without deleting the note. The top-right plus button bookmarks the active document. File and tab context menus also support bookmarking.

Customize the sidebar display name in plugin settings; leave it empty for the default.

## Interface visibility

In NoteGen versions that support display preferences, open Settings → Plugins → Installed → this plugin’s settings → Interface visibility. You can independently control the left sidebar tabs, file context menu, editor context menu, tab context menu, and editor toolbar. Entries are shown by default. Changes apply immediately and are saved for all workspaces on this device.

Hiding an entry keeps the plugin and its data. Commands remain available in the command palette. Hidden sidebar or editor views are not reopened automatically; enable the corresponding display option to see them again.
