# Bookmarks

Version 0.1.0 requires NoteGen 0.37.0 and plugin API 0.1.1.

Each item shows the filename and a body excerpt excluding level-one headings. Click to open, drag the entire row to reorder, or right-click to remove the bookmark without deleting the note. The top-right plus button bookmarks the active document. File and tab context menus also support bookmarking.

Customize the sidebar display name in plugin settings; leave it empty for the default.
