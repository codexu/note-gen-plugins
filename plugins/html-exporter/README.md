# HTML 高级导出

[English](README.en.md)

NoteGen 官方插件，使用可复用的 CSS 和 JavaScript 模板，将当前 Markdown 笔记导出为独立 HTML 文件，或复制 HTML 源码与富文本。输出包含尚未保存的正文，不改写原笔记。

插件版本为 **0.1.0**。需要桌面版 **NoteGen 0.39.1** 或更高版本，并实现插件协议 **0.1.12** 的 `html-export`、`html-copy` 能力；开发使用 SDK **0.1.14**。安装新版 SDK 不会给旧宿主增加能力。

- 点击状态栏“HTML 导出”打开居中弹窗，选择模板后可导出文件、复制 HTML 源码或复制富文本。
- 在同一弹窗内管理模板：新建、编辑、重命名、删除，默认样式不可修改或删除。模板保存在当前设备，最多 20 个自定义模板，单项 CSS 和 JavaScript 各不超过 10,000 个字符，总数据不超过 512 KiB。
- 升级时会保留先前保存的配置，将非空配置作为“原配置”模板使用；原始配置键不会被覆盖。保存失败不会丢弃原有模板。
- 复制 HTML 源码保留完整 HTML、模板 CSS 和 JavaScript。复制富文本只包含安全的富文本和可内联样式，不包含或执行 JavaScript；目标应用可能过滤样式、公式或图片。
- 读取当前编辑器和文件导出为必需权限；剪贴板写入和附件读取为可选权限。未授予剪贴板权限时仍可导出文件，图片需要授权目录才能嵌入。
- 输出使用点击时捕获的正文版本和模板。切换工作区、停用插件或撤回权限会阻止后续写入。资源或内容降级会显示提示。
- 完整提供英文和简体中文，界面语言跟随 NoteGen。

模板代码使用普通多行文本框，不提供语法高亮、预览、外部文件导入或依赖打包。插件不会在配置或输出过程中执行自定义脚本或获取远程资源，也不会修改 NoteGen 界面、普通 HTML 导出或 PDF 打印。导出文件和富文本可保留远程引用，打开或粘贴后的目标应用可能联网加载。

使用步骤和代码示例见 [中文使用说明](USAGE.zh-CN.md)。
