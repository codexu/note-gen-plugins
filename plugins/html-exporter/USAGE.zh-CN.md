# HTML 高级导出

需要支持插件协议 0.1.12 及 `html-export`、`html-copy` 能力的桌面版 NoteGen 0.39.1 或更高版本。

## 选择模板并输出

1. 启用插件，授予读取当前编辑器和文件导出权限。如需复制，请额外授予可选的剪贴板写入权限。
2. 打开 Markdown 笔记，点击状态栏的“HTML 导出”，在弹窗中选择模板。
3. 选择“导出 HTML 文件”“复制 HTML 源码”或“复制富文本”。导出文件需要在系统保存窗口选择位置；取消不会被视为失败。
4. 查看弹窗中的资源或内容提示。源码可粘贴到代码编辑器，富文本可粘贴到支持富文本的应用。

状态栏入口被隐藏时，可在 NoteGen 的插件展示设置中重新显示，或通过命令面板执行“打开 HTML 高级导出”。没有活动笔记时可管理模板，但不能输出。

## 管理模板

点击弹窗中的“管理模板”，可以新建、编辑、重命名和删除自定义模板。删除前需确认；删除选中模板后回到默认样式。默认样式不可编辑或删除。

每个模板有名称、CSS 和 JavaScript。直接填写代码，无需 `<style>` 或 `<script>` 标签；CSS 和 JavaScript 各不超过 10,000 个字符，最多 20 个自定义模板、模板数据合计不超过 512 KiB。编辑后选择“保存”才生效；取消、Escape 或关闭弹窗会丢弃未保存的草稿。

此前保存的非空 CSS 或 JavaScript 会作为“原配置”模板并被选中。旧配置键保留；读取或保存失败时不会用空配置覆盖原数据。

```css
body.notegen-export { max-width: 960px; font-family: Georgia, serif; }
.notegen-export h2 { color: #245577; }
```

```javascript
document.querySelectorAll('h2').forEach(heading => {
  heading.title = heading.textContent || '';
});
```

## 文件、源码与富文本

导出文件与复制源码都使用完整 HTML，CSS 在默认样式之后，JavaScript 仅在浏览器打开文件时运行。复制源码将完整 HTML 写入剪贴板文本。

复制富文本写入可供目标应用粘贴的 HTML 片段和纯文本。宿主将可安全转换的样式内联；不支持的 CSS、公式或其他内容会降级并给出提示。富文本不包含或执行 JavaScript。目标应用可能过滤内联样式、数据图片或远程引用，显示效果取决于目标应用。

宿主在输出前捕获所选编辑器的正文版本和模板。如果捕获前正文变化，会提示重试；之后的编辑不会改变这次输出。切换工作区、停用插件或撤回权限会阻止后续写入。

授权附件目录中的本地图片可嵌入；未授权或超限资源会产生提示。输出过程中不会请求远程图片、字体或 CSS 依赖；结果可能保留远程引用，目标应用打开文件或粘贴富文本时可能联网。HTML 文件的 CSS 和 JavaScript 以内嵌数据资源形式保存，其外部依赖需使用绝对 URL 或数据 URL，不支持 CSS 相对资源路径和脚本相对导入。

本版不提供预览、文件导入或资源目录打包。插件不具备通用文件系统、剪贴板读取或网络权限，系统保存路径不会返回给插件。
